# Known-failing backend tests, as of t_2af95a6b (2026-10-01).
#
# WHY THIS FILE EXISTS
# --------------------
# The backend-test job in .github/workflows/ci.yml carried
# `continue-on-error: true`, so a failing pytest run could not fail the
# workflow. 19-21 tests were red for the entire life of the tree and every PR
# stayed green. Removing the flag outright would turn main permanently red on
# the first push, so instead the suite is gated against this baseline:
#
#   * a test that fails and is NOT listed here  ->  the job fails
#   * a test that is listed here                ->  reported, tolerated
#   * a listed test that now passes             ->  reported as a warning, so
#                                                  the entry gets deleted
#
# This is a ratchet, not an excuse. Entries may only be REMOVED, never added
# silently, and scripts/ci_backend_gate.py enforces that: an entry with no
# written reason fails the job. That is the specific failure mode this card
# exists to stop — the "pre-existing, ignore it" framing is what let the suite
# rot while CI stayed green.
#
# Re-derived against `main` @ 01ec239b, on a clean Postgres 16.15 built by
# `alembic upgrade head`. The audit that classified most of these is
# docs/QA_T46761765_FAILURE_AUDIT.md (branch qa/t_46761765-failure-audit):
# 0 real production defects, 1 real test defect with a security consequence
# (already fixed), the rest defective tests.
#
# The list is re-verified against whatever main is at the time, so it will
# drift as sibling cards land. The gate reports entries that now PASS as
# STALE — delete those. The three `test_routers_products` entries that were
# here earlier are already gone: t_6edcf426 deleted the dead /api/products
# route, so the tests no longer exist.
#
# OWNERS: t_9edcc69c (QA-4 defective tests) and t_ee78caa8 (QA-1 duplicate
# PaymentInitiateRequest) are in flight; entries should disappear as they land.
#
# FORMAT: one "path::Class::test" per line, `#` comments and blank lines
# ignored. A reason block (a comment containing a marker word) covers every
# entry up to the next blank line.
